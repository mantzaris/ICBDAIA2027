PROJECT AND AUTHORIZATION

Working title: Evidence-Guided Regeneration of Underwater Acoustic Data with Generative AI: Selective Waveform Inpainting.
Target: ICBDAIA 2027. This is a separate study from an MVML paper about agents interpreting acoustic evidence. This project studies restoration decisions and reconstructed waveforms. It contains no LLM, agent reasoning benchmark, or generative training-data augmentation. Document shared preprocessing or datasets in OVERLAP.md; do not reuse manuscript text, result tables, or claim the same contribution twice.

Research question: With a fixed inference budget, can observation-only diagnostic probes and a separately calibrated acceptance rule reduce harmful generative gap completions while preserving acoustic fidelity and downstream utility on unseen vessel recordings?

Here regeneration means conditional waveform inpainting at known missing sample locations. It is an umbrella description, not a claim to have invented a new task. The contribution to test is a selective decision mechanism around an existing class of generators. Diffusion, observation projection, sampling several candidates, and calibration are established components. Do not claim first underwater diffusion, first underwater inpainting, or guaranteed recovery of unobserved events.

CORE MODEL AND LOSSES

Local model identifiers are project names, not existing published checkpoints:
  conditional_diffwave_8k_v1
  deterministic_diffwave_8k_v1
  repaint_diffwave_8k_v1

Use a DiffWave-style 1D residual network: residual_channels=64; residual_layers=36; dilation_cycle_length=12; kernel_size=3; gated residual/skip blocks; diffusion embedding as in the reference implementation. Dilations repeat 1,2,...,2048 three times. This provides about 3.07 seconds of receptive field at 8 kHz. Preserve the standard residual scaling. Remove the mel upsampler and add a sample-aligned conditioning projection of observed waveform y and binary mask m at each residual block. Report actual parameter counts and measured peak VRAM. Start with width 32 and 12 layers only for the pilot smoke test, then test the final architecture before committing the budget.

Define m[n]=1 for observed samples and 0 inside the known gap, h=1-m, y=m*x. The real recording x is the reference for recovery of a deleted region, not a noise-free source. The task does not remove ambient ocean noise.

Conditional diffusion training uses 1000 steps and a cosine cumulative-alpha schedule. At time t:
  z_t = m*y + h*(sqrt(alpha_bar_t)*x + sqrt(1-alpha_bar_t)*epsilon)
  L_diff = sum(h*(epsilon - epsilon_theta(z_t,t,y,m))^2) / sum(h)
Only missing coordinates are diffused and scored. This is an adaptation of established conditional masked diffusion, not the novel component. Train on G with random masks. No classifier guidance, AIS labels, text conditioning, or reference information at inference. Use DDIM with independent initial gap noise, eta=0, and 32 denoiser evaluations per draw. Reinsert y on observed coordinates at every reverse step and at the final output. Evaluate 64 steps on V during the pilot; adopt them only if the benefit justifies doubling all matched budgets.

For the deterministic learned baseline, use the same residual backbone receiving y,m without diffusion noise, outputting missing samples. Train with:
  L_det = masked_MAE + 0.5 * multi_resolution_spectral_convergence
Use STFT window sizes 64,128,256 within the gap, Hann windows, hop=window/4, center=False, normalized=True. Train both learned models on the same sources and mask distribution. Do not train the deterministic baseline with less source diversity to favor diffusion.

Optimization defaults: AdamW; learning_rate=2e-4; weight_decay=1e-4; effective_batch_size=16; microbatch chosen by memory measurement; gradient_clip_norm=1; BF16 where supported with FP32 metric calculations; exponential moving average decay=0.999. Maximum 60,000 optimizer updates per diffusion seed and 30,000 per deterministic seed. Validate every 2,000 updates, early-stop after five non-improving validations, using V only. Record all validation decisions. Training seeds: 17,29,43. Freeze architecture after the pilot; no test-driven tuning.

EVIDENCE GUIDED CANDIDATE SELECTION

1. Given y,m, generate K=4 conditional-diffusion candidates, each with 32 evaluations and distinct fixed seeds. Hard-project observations for all candidates.
2. Create two additional diagnostic probe gaps in observed context, one on either side of the real gap where possible. Each has the same duration as the real gap and a 64-ms guard. Neither overlaps the real gap. Hide each probe value before computing features, normalization, or model input. The real gap stays masked during both probes. Generate ONE reconstruction per probe, and also run B there. The genuine observed probe samples are used ONLY to score these diagnostic reconstructions. If two probes cannot be formed, flag the condition and return B under the primary policy. No hidden original-gap sample is ever used.
3. For each candidate collect scalar features: gap duration; available context lengths; left/right observed log-PSD distance; local observed RMS and spectral flatness; normalized amplitude and derivative mismatch at gap boundaries; gap-to-observed energy ratio; distance from B in waveform and spectral magnitudes; mean/max candidate-pool spectral dispersion; its distance from the pool medoid; and each probe's Q difference between generator and B. Include missing-feature indicators. Avoid class labels, downstream predictions, and hidden references.
4. Fit a HistGradientBoostingRegressor on D to predict delta_k = Q(candidate_k,x)-Q(B,x). Defaults: max_iter=200, max_leaf_nodes=15, learning_rate=0.05, l2_regularization=1, min_samples_leaf=20. Equalize recording-group weights so long recordings do not dominate. Use grouping for any cross-validation. G must not include D. Reference targets are permitted for fitting this predictor on D, never for test inference. One fit per generator seed. Tune at most the stated small hyperparameter alternatives on V and log them.
5. Select the candidate with the smallest predicted delta. Acceptance requires this score to pass the independent calibration threshold below and finite output/validity checks. Otherwise return B. Always emit accept/reject, score, probe metrics, candidate identifiers, computation count, and the provenance mask. This is a fixed-pool decision process, not an adaptive outer regeneration loop. Diffusion reverse steps are internal sampling steps. Do not invent a new iteration claim.

LOSS USED BY THE RISK DECISION

Let N be gap-only NMSE = sum((xhat_gap-x_gap)^2)/max(sum(x_gap^2), epsilon_energy), where epsilon_energy is based on the observed-signal RMS floor and gap length, fixed from G. Let S be the average of gap-only spectral convergence at STFT sizes 64,128,256:
  S = mean_r ||abs(STFT_r(xhat_gap))-abs(STFT_r(x_gap))||_F /
             max(||abs(STFT_r(x_gap))||_F, epsilon_spectral_r).
Use floors fixed from G, document numerical definitions, and report quiet/near-silent examples separately.
  Q = 0.5*min(N/4,1) + 0.5*min(S/2,1).
Q is in [0,1]. A harmful generative decision has Q(candidate,x)-Q(B,x)>0.02. These weights, caps, and the 0.02 harm margin are preregistered engineering choices, not perceptual or physical laws. Always also report uncapped N and S, so clipping cannot hide catastrophic errors. Use the same definition for diagnostic probes.

CALIBRATION WITHOUT TEST LEAKAGE

On V, freeze up to nine acceptance-score thresholds from quantiles {0.05,0.10,0.20,0.30,0.40,0.50,0.60,0.80,1.00}, capped at 0 because predicted worsening should not be accepted. Freeze the selected candidate policy before opening C.

On C, draw exactly ONE representative source crop and ONE gap case per independent group using a frozen random seed, with duration uniform over 50,100,250,500 ms. This defines the group-balanced deployment distribution used for calibration. For each threshold, count accepted cases n and harmful accepted cases e. Compute a one-sided Clopper-Pearson upper bound U=BetaQuantile(1-0.05/M; e+1,n-e), with U=1 if e=n or n=0, where M is the number of tested thresholds. Accept thresholds only if U<=0.10. Pick the eligible threshold with largest accepted count; deterministic tie break to the stricter threshold. If none passes, use B everywhere and report zero generative coverage. Do not lower the standard after seeing failure.

This is simultaneous binomial calibration of selective harm, credited to risk-control literature. Its finite-sample interpretation assumes independent, identically distributed calibration/test group draws and a frozen policy. It is not a conditional guarantee for each waveform, not automatically valid for every gap duration separately, and not valid under arbitrary ocean/site shift. Correlated sessions and AIS grouping can violate independence; report those limits. Do not apply ordinary pointwise conformal coverage and claim it controls post-selection error. Report empirical calibration curves and accepted-sample harm on the external archive without a transferred guarantee.

STRESS TESTS AND SYNTHETIC MECHANISMS

Use 750- and 1000-ms gaps as out-of-training-range tests. Also test four 50-ms packet-like erasures, smooth changes in level/spectrum across a gap, and cases with insufficient context. Mark these as distribution shift; report fallback frequency and failure rather than retuning.

Generate a separate diagnostic synthetic suite at 8 kHz using randomized mixtures of 1-6 tones/chirps (30-1500 Hz), amplitude modulation (2-20 Hz), colored broadband noise with PSD proportional to f^(-beta), beta in [0,2], and isolated transients. Vary component-to-background SNR over -5,0,10,20 dB. Add optional 2-4 delayed, attenuated copies with delays 1-20 ms. These are controlled signal constructions, not a validated underwater propagation simulator. Evaluate the real-trained model without fitting to the synthetic test signals. Use 100 distinct parameter/noise realizations per main mechanism and pair methods on identical seeds.

Include stationary continuation, gradual chirp, onset/offset at the gap, broadband-only background, and a fully hidden transient. Crucially construct paired targets x_a and x_b that are identical outside the gap but differ by an event entirely inside it. With the same sampler seed, the method must receive identical input and produce identical output for both. Quantify the consequent false-event versus missed-event tradeoff; this is an identifiability limit, not a bug or evidence that the hidden event was recovered.

Do not force continuation of every line observed outside a gap: real events can start or end inside it. Candidate disagreement is a diagnostic, not proof that an event is true or absent. Uncertainty and fallback can limit unsupported decisions but cannot reveal invisible content.

PREREGISTERED DECISION CRITERIA

The primary selective-regeneration claim is supported only if:
  1. Generative coverage on held-out real groups is at least 25%.
  2. All-case harmful-decision rate falls by at least 25% relative to C3, with a paired confidence interval excluding no reduction. If C3's harm is already negligible, report that the reduction target is uninformative rather than manufacturing a ratio.
  3. At matched coverage, the complete diagnostics improve the harm/coverage tradeoff over duration-only and dispersion-only gating.
  4. Whole-pipeline mean Q is no worse than B by more than 0.01, with a one-sided 95% upper bound, and macro-F1 is no worse than B by more than 0.02 absolute, with a one-sided 95% lower bound.
  5. Observed samples are preserved within floating-point tolerance (target max drift <=1e-6 on normalized data).

An additional average-fidelity superiority claim requires at least 5% relative reduction in gap spectral convergence against B and the V-selected equal-budget ungated comparator, with paired intervals excluding zero. Do not replace missing average gains with classifier confidence. External generalization is a separate empirical claim and requires the corresponding direction of benefit on VLIZ without recalibration. Failure to satisfy any criterion narrows or rejects that claim; it does not justify changing the criterion after opening test results.
