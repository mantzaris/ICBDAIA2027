# Relationship to the MVML study

This study concerns restoration decisions and reconstructed waveforms. The user
subsequently expanded its scope to include GPU comparisons of direct, reasoning,
self-reviewing, and paired language-model agents. It does not evaluate generative
training-data augmentation.

The operator workflow covers evidence labels, analysis-setting choices, and review
through a tool-using agent. An earlier CPU demonstration executes one local Llama 3.1 8B episode on
an existing V case, followed by one explicit post hoc execution-audit continuation.
It illustrates numeric tool use and virtual analysis-window configuration. The
first unsupported comparison claim, completed missing actions, and remaining prose
limitations are retained. This is not a general reasoning evaluation. No independent
object-identification model or physical equipment interface was implemented.

The subsequent correction experiment changes the conditional diffusion prediction
target to the established velocity formulation of Salimans and Ho. Its scope is
numerical diagnosis and acoustic reconstruction on reused development groups.
That correction itself adds neither a language-model agent nor an object-identification
experiment, and does not claim invention of velocity prediction or diffusion inpainting.
The new Qwen3-8B comparison evaluates a different, bounded task: choose a feasible
analysis window, label measured acoustic cues, configure a virtual display, and
verify the result. Its four neural approaches share weights and resource ceilings;
a fixed-rule solver implements the task policy. A separately frozen follow-up
tests a configuration feasibility gate on new source groups and dates. Source
identity remains unknown. A further budget-sensitivity check reuses the first sixteen primary tasks; it does
not add independent data. These experiments do not evaluate vessel classification
or physical equipment control and do not reproduce an MVML benchmark.

No MVML source code, manuscript text, results, or tables have been imported. Actual
shared datasets and preprocessing must be recorded here if reuse occurs. Dataset
ancestry alone does not establish independent external evaluation: DeepShip and
UniqueShip both draw on Ocean Networks Canada material.
