# Acoustic examples and AI assistance

These fifteen clips accompany the three examples in the paper. For each case,
`reference` is recorded audio, `masked` erases the evaluated gap, `fallback_B_equals_P`
contains a learned baseline estimate, `selected_C3` contains an original diffusion
proposal, and `velocity_first` contains the corrected diffusion model’s first proposal.
The methods and selection rules are described in `../../manuscript/mainj.tex`.
Estimated sound is not a recording of the missing event or evidence of vessel identity.

OpenAI Codex assisted in the code production, and manuscript draft editing.
The clips derive from recorded inputs and saved experimental waveform outputs, not
new audio generated for this writing revision. No listening study is claimed.

Source recordings are credited to UniqueShip and Ocean Networks Canada under

[selection and processing records](../../figures/acoustic_example_selection.json),
and the [full project README](../../README.md) provide the source details.
