Open index.html in a browser. All case data, images and audio are local; no server or GPU is needed for replay.
The cursor links original-recording seconds across LOFAR/DEMON. Select a component to inspect overlapping intervals and cited evidence.
Drag across a plot to select an interval. Raw/contrast switches change display only. Recorded action images remain unmodified.
Local correction notes are stored separately in this browser and may be exported; they never overwrite benchmark annotations.
Optional new measurements require scripts/serve_viewer_gpu.py on an available CUDA machine, bound to 127.0.0.1 only.
Exploratory reinspection is excluded from the frozen benchmark. This local audio package does not assert redistribution permission.
